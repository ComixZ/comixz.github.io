❓ « Anti-Comic-Chaos-Tool » est un petit programme qui vous permet de gérer votre collection de comics - conçu à l'origine pour les comics en langue allemande, mais il fonctionne tout aussi bien avec des comics en anglais, en français ou dans d'autres langues. Que vous possédiez 10 mangas ou une collection Disney complète : avec cet outil, vous saurez toujours ce que vous possédez déjà.

😁 Rien à installer. Pas d'assistant d'installation, pas d'inscription, pas de publicité. Le dossier complet contenant le programme fonctionne tel quel - vous pouvez donc aussi simplement le copier sur une clé USB et continuer à l'utiliser sur un autre PC.

⚠️ Ces 2 fichiers et le dossier correspondant doivent toujours rester ensemble dans le même répertoire (c'est-à-dire le même dossier sur le disque dur ou la clé) :

  • Le fichier du programme : « acct.exe » (c'est ce que vous lancez pour ouvrir le programme)
  • Le fichier de paramètres : « comic.ini » (c'est là que le programme mémorise vos réglages)
  • Un dossier nommé « DB_nom de la base de données » - il contient toutes les images ainsi que le fichier de la base de données proprement dit.

Si vous créez plusieurs bases de données (par exemple parce que vous voulez séparer mangas et comics), le programme crée automatiquement un dossier propre à chacune, par ex. « DB_nom de la base de données1 », « DB_nom de la base de données2 » et ainsi de suite. Vous n'avez pas à vous en occuper vous-même, le programme les crée tout seul.

0️⃣ Cours accéléré

Saisir et modifier des comics est en fait assez intuitif - le mieux est de simplement regarder le formulaire de saisie et d'essayer par vous-même. Quelques petites choses fonctionnent toutefois un peu différemment de ce à quoi vous êtes peut-être habitué avec d'autres programmes :

  • Dès que vous modifiez quelque chose quelque part puis cliquez sur « OK », c'est immédiatement et automatiquement écrit dans la base de données. Il n'y a volontairement pas de bouton « Enregistrer » ou « Enregistrer sous » comme vous en connaissez peut-être dans Word ou d'autres programmes.
  • À côté de certains champs de saisie, vous verrez une petite flèche ▼ sur la droite. En cliquant dessus, une liste s'ouvre avec les valeurs déjà saisies dans ce champ auparavant (par ex. noms de dessinateurs ou de scénaristes) - vous n'avez donc pas besoin de tout retaper à chaque fois, vous pouvez simplement cliquer sur une entrée existante. Vous pouvez tout aussi bien taper quelque chose de complètement nouveau dans le champ si le nom souhaité ne figure pas encore dans la liste.
  • Si vous ajoutez plusieurs numéros d'une série (par ex. Astérix numéro 10 à 33), le programme les regroupe automatiquement dans la fenêtre principale sous le nom commun « Astérix » afin que la liste reste claire. À gauche d'un tel nom de série, vous verrez une petite icône en forme de flèche . Cliquez dessus pour afficher ou masquer tous les numéros individuels de cette série.
  • Vous souhaitez sélectionner plusieurs comics en même temps (par ex. pour tous les supprimer ou les modifier d'un coup) ? Cela fonctionne exactement comme vous le connaissez dans l'Explorateur Windows : maintenez la touche CTRL enfoncée et cliquez successivement sur chaque comic souhaité pour ajouter ou retirer des comics individuels de la sélection. Vous pouvez aussi maintenir la touche MAJ enfoncée et cliquer sur le premier puis le dernier comic d'une série pour sélectionner d'un coup tout ce qui se trouve entre les deux.

1️⃣ Créer une édition intégrale

Une « édition intégrale » est un volume épais dans lequel plusieurs numéros individuels d'une série ont été réimprimés ensemble (par ex. « Astérix Intégrale : Tomes 1 à 3 en un seul livre »). Pour que le programme reconnaisse cela et associe correctement les numéros, vous devez marquer ce volume comme édition intégrale. Cela fonctionne aussi bien lors de la création que, par la suite, lors de la modification d'un comic déjà existant :

  1. Ouvrez soit « Nouveau comic » (pour une nouvelle entrée), soit « Modifier le comic » (pour une entrée déjà existante).
  2. Cherchez la case à cocher intitulée « Édition intégrale » et cliquez dessus une fois, de sorte qu'une coche apparaisse.
  3. Vous devez maintenant indiquer quels numéros font partie de cette édition intégrale. Si vous avez déjà créé les numéros individuels au préalable dans votre base de données, cliquez sur la petite flèche à côté du champ de saisie - une liste s'ouvre, dans laquelle vous pouvez simplement sélectionner les numéros correspondants. Si vous n'avez pas encore d'entrées correspondantes, tapez simplement le nom directement dans le champ.
  4. Avec « Ajouter d'autres numéros », vous pouvez ajouter encore plus de numéros à cette édition intégrale, s'il en manque.
  5. Pour finir, confirmez comme d'habitude avec « OK » pour que tout soit enregistré.

2️⃣ Créer une anthologie

Une « anthologie » est un numéro qui contient non pas une, mais plusieurs histoires différentes (souvent de dessinateurs/scénaristes différents). Pour que vous puissiez ensuite retrouver dans votre base de données quelle histoire se trouve où, vous devez marquer un tel numéro comme anthologie. Cela fonctionne aussi bien lors de la création que, par la suite, lors de la modification d'un comic déjà existant :

  1. Ouvrez soit « Nouveau comic » (pour une nouvelle entrée), soit « Modifier le comic » (pour une entrée déjà existante).
  2. Cherchez la case à cocher intitulée « Anthologie » et cliquez dessus une fois, de sorte qu'une coche apparaisse.
  3. Saisissez le titre de la première histoire dans le champ prévu à cet effet - ce champ est obligatoire, impossible de continuer sans titre. Dessinateur, scénariste et nombre de pages peuvent également être saisis, mais ce n'est pas obligatoire (optionnel).
  4. Si le même numéro contient d'autres histoires, cliquez sur « Ajouter d'autres numéros » et saisissez de la même manière le titre (et éventuellement dessinateur/scénariste/pages) de l'histoire suivante. Répétez cela jusqu'à ce que toutes les histoires du numéro soient saisies.
  5. Pour finir, confirmez comme d'habitude avec « OK » pour que tout soit enregistré.

3️⃣ Lot - créer plusieurs comics à la fois

Vous avez par exemple Astérix numéro 1 à 10 et vous ne voulez pas les taper dix fois un par un ? C'est exactement à cela que sert « Lot ». Il vous permet de créer d'un coup plusieurs numéros d'une série en une seule fois, au lieu de saisir chacun séparément via « Nouveau comic ».

  1. Créez d'abord un nouveau comic normalement et remplissez Série, Éditeur, etc. comme d'habitude.
  2. Cherchez la case à cocher « Lot » et cochez-la. Dès qu'elle est cochée, un nouveau champ apparaît, dans lequel vous pouvez saisir une plage de numéros. Ce nouveau champ comporte « de » et « à ». Dans « de », saisissez le premier numéro de fascicule (par ex. 1), dans « à » le dernier (par ex. 10). Le programme crée alors automatiquement tous les numéros 1 à 10 pour vous - vous n'avez pas besoin de taper chaque numéro individuellement.
  3. Pour que chaque numéro n'ait pas la même image de couverture, cliquez sur le bouton avec l'icône de dossier. Une nouvelle fenêtre supplémentaire s'ouvre alors.
  4. Dans cette nouvelle fenêtre, vous voyez une liste de tous les numéros que vous êtes en train de créer (par ex. numéro 1 à numéro 10). Cliquez à l'endroit correspondant pour chaque numéro individuel et choisissez son image de couverture, saisissez titre et ISBN. Faites cela une fois pour chaque numéro, jusqu'à ce qu'ils aient tous leur propre couverture.
  5. Une fois terminé, confirmez avec « OK » (comme d'habitude) - c'est seulement alors que tous les numéros sont réellement enregistrés dans la base de données.

4️⃣ Créer un groupe & y associer des comics

⚠️ Important : « Créer un groupe » crée uniquement un espace réservé vide - aucun comic n'y est encore associé. C'est une seconde étape, séparée, qui suit.

Un groupe rassemble plusieurs séries qui vont ensemble sur le plan du contenu (par ex. une série principale + des dérivés), et c'est aussi l'endroit où vous pouvez déposer des images de coffret, de figurines et d'artworks qui appartiennent à tout le groupe plutôt qu'à un seul numéro.

Étape 1 : créer le groupe

  1. Cliquez sur « Plus » dans la barre d'outils.
  2. Cliquez sur « Créer un groupe ».
  3. Saisissez le nom souhaité (par ex. « Astérix »).
  4. Cliquez sur OK.

C'est tout pour cette étape - le groupe existe maintenant, mais il est encore complètement vide. Aucun numéro n'y est encore rattaché.

Étape 2 : associer des comics au groupe

Pour qu'un comic appartienne réellement à ce groupe, vous devez le saisir pour chaque numéro individuellement - ou bien sélectionner plusieurs numéros au préalable :

  1. Ouvrez le numéro via « Modifier ».
  2. Dans le champ « Groupe », sélectionnez via la liste déroulante le nom que vous avez attribué à l'étape 1.
  3. Enregistrez avec OK.

Répétez cela pour chaque numéro qui doit appartenir au groupe. La « Série » du numéro (c'est-à-dire son nom sur la couverture) reste inchangée - seule l'association au groupe change.

Ce qui change en conséquence

  • Dans le tableau, tous les numéros partageant le même groupe sont désormais affichés ensemble sous un en-tête de groupe (par ex. « Astérix (10 numéros) »), même s'ils ont des noms de série différents.
  • En cliquant sur « Modifier » sur cet en-tête de groupe, vous ouvrez « Modifier la série » - vous pouvez y télécharger en plus des images de coffret, de figurines et d'artworks pour tout le groupe.

💡 En résumé : « Créer un groupe » ne fait que créer le dossier vide. Les numéros doivent ensuite y être placés individuellement via leur propre champ « Groupe ».

5️⃣ Vérifier les couvertures & les vignettes

C'est ici que vous trouvez et nettoyez les problèmes dans le dossier de couvertures de votre base de données - images superflues, couvertures enregistrées en double, et comics auxquels il manque encore une image.

Ouvrir : Menu/Bases de données → Vérifier les couvertures

La fenêtre comporte trois onglets en haut, entre lesquels vous pouvez basculer.

Onglet 1 - Trouver les couvertures inutilisées

Affiche les images enregistrées dans le dossier de couvertures mais qui n'appartiennent plus à aucun comic (par ex. parce que le comic a été supprimé mais que l'image est restée).

  1. Ouvrez l'onglet « Trouver les couvertures inutilisées » (déjà sélectionné par défaut).
  2. Vous voyez une liste des images trouvées, avec un petit aperçu.
  3. Cochez les images que vous souhaitez supprimer.
  4. Cliquez sur « Supprimer ».

👍 S'il est indiqué « Aucune couverture inutilisée » avec une icône de pouce levé, tout est propre - rien à faire.

Onglet 2 - Trouver les couvertures en double

Affiche les images enregistrées plusieurs fois dans le dossier de couvertures (sous des noms de fichiers différents, mais identiques ou très similaires sur le plan du contenu).

Le curseur de sensibilité (détection de similarité)

Le programme compare automatiquement toutes vos images de couverture entre elles et essaie de déterminer lesquelles sont en fait la même image. Le curseur « Sensibilité » détermine à quel point cette comparaison doit être exacte pour que deux images soient considérées comme « identiques ».

  • Curseur tout à gauche (valeur basse, stricte) : Ne compte comme « identique » que si les images sont vraiment quasi identiques pixel par pixel. Peu de résultats, mais très fiables - certains vrais doublons (par ex. légèrement recadrés ou compressés différemment) sont ainsi manqués.
  • Curseur tout à droite (valeur haute, généreuse) : Compte déjà comme « identique » si les images ne se ressemblent que grossièrement. Plus de résultats - mais le risque augmente que des couvertures en réalité différentes soient classées à tort comme « identiques ».

Il n'y a pas de valeur « correcte » - cela dépend de l'apparence de vos couvertures. Déplacez le curseur et observez comment la liste de résultats en dessous s'ajuste immédiatement.

💡 Si un nom de comic est indiqué à côté d'une image, elle appartient à ce comic - en général, vous ne devriez pas la supprimer. Si aucun nom n'est indiqué à côté, elle n'appartient à aucun comic et peut généralement être supprimée sans risque.

  1. Ouvrez l'onglet « Trouver les couvertures en double ».
  2. Ajustez la sensibilité si nécessaire.
  3. Parcourez les groupes trouvés - vérifiez chaque image individuellement via l'aperçu pour voir s'il s'agit vraiment d'un doublon.
  4. Ne cochez que ce que vous voulez vraiment supprimer.
  5. Cliquez sur « Supprimer ».

⚠️ Vérifiez que les couvertures sont vraiment identiques avant de supprimer ! La détection automatique peut se tromper, en particulier avec des couvertures ayant un cadre/une mise en page similaire mais un contenu différent - le curseur n'est qu'une aide, pas une garantie.

Onglet 3 - Comics sans couverture

Affiche les comics de votre base de données auxquels aucune image n'est encore associée (vous les reconnaissez dans le tableau normal à l'icône d'appareil photo à la place d'une couverture). Vous ne pouvez rien supprimer directement ici - la liste sert uniquement à donner une vue d'ensemble. Cliquez sur une entrée pour modifier le comic concerné et y ajouter une image.

Vérifier les vignettes

Les images de couverture peuvent peser plusieurs Mo - plus il y en a, plus le chargement est long. C'est pourquoi le programme crée automatiquement de petites copies à chargement rapide (« vignettes »). Cela se fait en principe tout seul, vous n'avez normalement pas à vous en occuper.

Si quelque chose s'est mal passé (par ex. après un plantage ou des interventions manuelles dans le système de fichiers), « Vérifier les vignettes » vérifie qu'une copie miniature existe bien pour chaque couverture, et complète automatiquement celles qui manquent.

Ouvrir : Menu/Bases de données → Vérifier les vignettes

  1. Cliquez sur « Vérifier ».
  2. Le programme parcourt en arrière-plan toutes les couvertures (cela peut prendre un moment avec beaucoup de comics).
  3. Les vignettes manquantes sont recréées automatiquement.

💡 Que se passe-t-il s'il manque une vignette ? Rien de grave - l'application fonctionne quand même parfaitement, les images se chargent juste un peu plus lentement jusqu'à ce que vous exécutiez cette fonction une fois.

💡 En résumé : « Vérifier les couvertures » nettoie le dossier d'images, « Vérifier les vignettes » répare les aperçus rapides - vous pouvez lancer les deux sans risque de temps en temps, mais avec « Trouver les couvertures en double », vérifiez toujours vous-même avant de supprimer.

6️⃣ Importer des comics

C'est ici que vous récupérez des comics d'une autre base de données vers votre base de données actuellement ouverte.

Étape 1 : ouvrir la fenêtre

  1. Cliquez sur « Plus » dans la barre d'outils.
  2. Cliquez sur « Importer des comics ».

Étape 2 : sélectionner un fichier

Vous voyez une liste de toutes les autres bases de données trouvées. Cliquez sur le nom de la base de données depuis laquelle vous voulez récupérer des comics - elle est alors mise en surbrillance.

Étape 3 : confirmer

Dès qu'un fichier est sélectionné, le bouton OK apparaît. Cliquez dessus.

Ce qui se passe ensuite

  • Tous les comics du fichier sélectionné sont repris dans votre base de données actuelle.
  • Les comics correspondant exactement, sur le plan du contenu, à un comic déjà existant ne sont pas importés en double.
  • Les images associées (couverture, tirage d'art, coffret, figurines, artworks) sont automatiquement reprises également.
  • Une fenêtre de résultat vous montre à la fin combien de comics ont été repris et combien ont été ignorés en tant que doublons.

💡 L'autre base de données reste inchangée dans le processus - seules des copies sont reprises dans votre base de données actuelle, rien n'est supprimé du fichier source.

💡 En résumé : « Importer des comics » est un sens unique vers votre base de données actuelle - sans risque à essayer, puisque le fichier source n'est jamais modifié.

7️⃣ Exporter des comics

C'est ici que vous copiez (ou déplacez) une sélection de vos comics vers une autre base de données - soit une nouvelle, soit une qui existe déjà.

Étape 1 : sélectionner des comics

Dans le tableau, sélectionnez les comics que vous souhaitez exporter. Le bouton « Exporter des comics » (sous « Plus ») ne devient cliquable qu'une fois qu'au moins un comic est sélectionné.

Étape 2 : choisir la destination

  • Nouveau fichier : Une toute nouvelle base de données est créée, ne contenant que les comics sélectionnés. Vous lui donnez un nom.
  • Base de données existante : Les comics sélectionnés sont ajoutés à une base de données déjà existante. Vous choisissez le fichier de destination dans une liste.

Étape 3 : choisir Copier ou Déplacer

  • Copier (par défaut) : Les comics se retrouvent en plus dans la base de données de destination - ils restent inchangés dans votre base de données actuelle.
  • Déplacer : Les comics sont transférés vers la base de données de destination et supprimés de votre base de données actuelle. Les images associées sont également déplacées (pas conservées en double) - sauf si un autre comic restant utilise encore exactement la même image (par ex. une couverture d'intégrale partagée), auquel cas elle est conservée par sécurité.

Étape 4 : confirmer

Cliquez sur OK.
